# 四流数据字典

一个数据集为一个目录。必须包含 manifest.json、cases.csv、sources.csv；其他表可为空表，缺失时会提示。所有CSV采用UTF-8，可带BOM。时间支持带时区的ISO格式；不带时区的时间按北京时间解释。

manifest.json 指定 schema_version=2（兼容1）、origin=real或synthetic、title、timezone及description。origin为提供方声明的来源类型，不等于系统验证其真实性。

| 表 | 主键 | 核心内容 |
| --- | --- | --- |
| cases.csv | case_id | title、region、case_type |
| sources.csv | case_id + source_id | title、reference；reference为数据目录内相对文件路径，或以ref:开头的材料引用 |
| actors.csv | case_id + actor_id | alias、actor_type、role、role_verified、source_id |
| funds.csv | case_id + tx_id | from_id、to_id、from_kind、to_kind、chain、timestamp、amount、currency、order_id、exchange_id、source_id |
| shipments.csv | case_id + shipment_id | order_id、from_place、to_place、sender_id、receiver_id、carrier_id、vehicle_id、timestamp、goods_label、service_type、source_id |
| communications.csv | case_id + event_id | from_actor、to_actor、timestamp、channel、device_id、summary、source_id |
| identity_links.csv | case_id + link_id | actor_id、entity_kind、entity_id、chain、timestamp、verified、verification_note、source_id |
| relations.csv | case_id + relation_id | from_actor、to_actor、relation、timestamp、verified、source_id |
| case_labels.csv | case_id | label、confirmed、label_source |
| person_labels.csv | case_id + actor_id | role_label、level_label、confirmed、label_source、timestamp；独立监督标签，不进入图特征 |

## 约束

- case_id只能含字母、数字、汉字、下划线和连字符，最长64字符。
- wallet表示链上地址，account表示法币账户。chain必须填写链名或账户域，防止不同链同字符串被误并。
- 资金金额必须为有限正数，币种必填。每笔原始交易唯一编号；订单支付和兑换事件派生边不重复计入交易额。
- 身份、主体关系、角色及标签的布尔字段必须明确填true/false或1/0。
- 主体引用必须存在于actors.csv；来源编号必须存在于同案件sources.csv。
- 0/1标签表示提供方已定义的目标异常模式有无，不是法律结论。confirmed=false的记录不进入训练；没有标签不代表正常。
- 数据集内来源文件的内容哈希会计入数据指纹。资料修订后，旧核验不会自动迁移到新数据版本。
- exchange_id表示来源材料明确记录的同一兑换事件。不同币种金额不换算或相加，系统不自动推断兑换率。
- 多条运输记录共用order_id可关联到同一订单；如需证明物品连续性，应在来源中提供批次/运单依据。

## 导入准备

从系统导出空模板，填入自己的脱敏记录。保留表头，即使某表没有记录也可仅留表头。来源材料放在目录内的evidence子目录，再用相对路径引用。不要填真实数据时仍保留synthetic标记，也不要把合成数据改标成real。

大规模数据建议先按案件及事件时间窗口划分。本地模型每图最多256节点，图像最多150节点；界面原始记录每次显示最多1000行。上述是显示和模型范围，不是导出统计自动截断交易的理由。

## IP与产业扩展

network_events.csv主键为case_id + access_id。列为actor_id、account_id、account_kind、chain、ip、device_id、timestamp、event_type、source_port、network_scope、source_id。主体与账户至少填写一项；账户存在时必须填写wallet/account类型和链或账户域；端口可留空，否则为1至65535。IP不能附带端口或接口区域后缀。非公网IP必须指定网络域；同域同IP才表示同一个网络观测节点，仍不表示同一使用人。

shipments.service_type支持telecom_equipment、account_service、software_service、logistics、other、unspecified。旧表缺该列时使用未分类，兼容原有数据。类别由来源提供，不能作为违法用途认定。

清洗输出含cleaning_report.json，记载变更、隔离行、原始文件SHA256与行号映射。保留原目录才能复核原始输入。额外未建模列不会进入模型，但会列明列名并保留在原始文件中。

## 1.1.1任务与核验约束

manifest.label_definition须明确task_id、positive、negative，训练和评分含义一致；未填写不影响图谱导入，但不能训练或评分。

复合实体ID对各分量独立编码，防止冒号、百分号等造成碰撞。timestamp为来源事件时间，effective_from为人工核验生效时间，二者不能混用。人工核验可覆盖当前有效状态，但不改写原始verified字段。

清洗报告包含output_sha256和原始映射stages；被修改的输出表不继续声明原始行号可核验。金额最多1000位有效数字、指数绝对值不超过1000；在此范围内汇总按输入尺度保留十进制精度。哈希用于版本一致性，不证明来源材料真实性或独立性。

## 1.2角色监督任务

manifest.role_task须指定task_id、roles角色字符串列表、levels从上到下的层级列表、compatible_pairs允许的角色/层级组合列表。分类任务依据业务核实定义，不预设所有案件都存在固定三层结构；模板中的四角色/三层仅为可修改示例，task_id留空，训练前必须核定。

人员标签timestamp为该标签可用于训练/探索的时间，不是事件时间。confirmed=true且来源有效的标签才用于监督；未标注人员不当作正常/底层。角色2至20类，层级2至8类，每种类别至少出现在一个允许组合中，组合不许重复。教师标签、姓名及原始角色不进入图特征。

## 1.2独立队列因果研究

研究使用另一目录：causal_design.json、observations.csv、sources.csv；它不是案件四流CSV的替代格式。data/causal_templates为空模板。

- 设计指定schema_version=1、origin、task_id、question、treatment、outcome、outcome_type、adjustment、dag.nodes/edges、unobserved_nodes、assumptions、acknowledged_by。处理必须为0/1；结果为连续有限数字或binary的0/1。
- 观测必填observation_id、group_id、covariate_time、treatment_time、outcome_time、source_id，以及设计中的调整、处理和结果列。重复列名、重复编号、缺失/非有限值被拒绝，不自动插补。
- 须满足协变量测量时间≤处理时间<结果时间。相关的重复测量使用同group_id；至少50条、10个独立组、两组各至少10条，5折按组留出。
- 来源表含source_id、title、reference；目录内相对路径或ref:引用。DAG最多50节点、12个调整变量；不允许环、未观测调整变量、处理后变量或未阻断的后门路径。
- assumptions包括consistency、no_unmeasured_confounding、positivity、pre_treatment_covariates、independent_groups，均须分析人员明确确认并填写确认人。真实研究界面不代填。

## 1.2材料提取与人工导入

result.json记录origin、来源SHA256、机器片段、候选字段和截断/抽帧情况；片段含页码/部件/音视频秒数、框坐标及方法。1.3默认对图文混合页同时保留文字层和页面OCR，view区分native_text/page_raster；双视图不代表独立材料；扫描页OCR坐标为144DPI栅格页像素。DOCX表格和段落编号是提取位置，不代表原版页码。

单独“元”不自动映射CNY；OCR分数和ASR诊断不是事实概率。人工确认后仅将修订摘要及人为指定的已有双方主体/时间写到新的communications.csv，附原材料、核验人和导入依据；不自动写funds或identity_links。

## 1.4高级辅助数据

manifest.advanced包含version=1、明确control_task正负含义、control_file、media_file及两表SHA256。control_labels.csv为case_id/from_actor/to_actor/label/confirmed/label_source/timestamp，未知不标0。multimodal_links.json登记case_id/table/record_id/source_id/path/sha256/confirmed/reviewer/available_at，必须为已核对的事件对应。媒体使用数据集内相对路径，且对应sources.csv同编号引用。可用时间不得早于事件；历史排除未来对应。辅助文件变化须重新核验清单。

实体输入沿用29维；事件10维为四流one-hot、锚点数log、距参考时刻年龄、距首事件小时log、confirmed标记、lineage标记及保留零位。控制对额外使用正反通信次数log和共同事件数log。无姓名、监督标签、来源原文或文件名输入。
