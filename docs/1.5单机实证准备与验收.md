# 1.5 单机实证准备与验收

2026-10-30。适用 Windows 单机本地、CSV/Excel 导入。对照《模型大纲》《第一章 执行摘要》，本轮补齐接入、分组隔离、流程编排、外部实证、版本与恢复，保留四流、资金/人员/双图模型、因果研究及材料识别。

自带监督权重仍是合成数据训练模型，不能用于真实案件评分。工程与合成验收不证明真实团伙控制恢复、现实因果识别或跨地区泛化。材料没有 HD-EIA/MOID-XAI 原方法的公式与代码，现有为独立定义的工程实现。

## 启动

项目在 `D:\Projects\FourFlowAnalysis`。双击 `启动系统.vbs`；或 PyCharm 打开项目，解释器选 `.venv\Scripts\python.exe`，运行根目录 `app.py`。修改后正常关闭旧窗口再重新启动。同一新版工作区限制单实例。

左侧新增“实证与运维”：接入与全流程、外部实证评测、模型版本、备份与恢复。导航可滚动；长任务后台运行，有进度，忙碌时暂停数据/时间切换及核验写入，避免快照错配。

## 接入真实数据

1. 原件先按项目授权范围脱敏并核实来源。点击“CSV/Excel接入”，填写案件编号、标题、地区、案型，来源选 `real`。合成演示单独选 `synthetic`。
2. 选择 `.csv`、`.tsv` 或 `.xlsx`，旧 `.xls` 需另存为 `.xlsx`。支持 UTF-8/GB18030。每文件最多 50MB、每表 5 万行/200 列，XLSX 展开体积另有限制。输入上限不代表已经完成该规模压力测试。
3. 选择工作表和接入类型，预览并核对每个列对应。中文表头建议不代替人工核验。编号/账号应是文本列；明确零填充格式可保留短数值的前导零，超出 Excel 精度的数值编号拒绝接入。格式不能恢复已丢失数字。公式不执行，映射到公式时须人工核对并另存为值。
4. 只有未映射字段才使用明确填写的默认值。例如账户域/账户类型须由来源确认，不得凭空补金额、时间、IP、身份或标签；确认标记为空时默认未经确认。
5. “加入接入队列”，可继续加入其他表。各案件信息分别保留；同案信息冲突、重复记录提示核对。真实与合成不得混入同一队列。
6. “生成并载入新数据集”另建 `data/imported/intake_时间`。原件副本、SHA256、工作表/原行号、列对应、错误和变更均保留。失败草稿不会载入，不覆盖原件。后续原件缺失/被替换或逐行来源不一致会拒绝沿用旧溯源；CSV引号内跨行文本保留实际起始行。
7. “清洗与质量”生成清洗副本，核对隔离记录。重复清洗和人工材料追加保留上游接入报告、工作表及原件指纹；追加材料同时保留任务/分组/高级辅助文件。只出现主体编号时只登记该编号，姓名/身份/角色未知；不同银行/链上同名账号须明确作用域，身份对应仍需来源与人工核验。

## 分析流程

“实证与运维 → 一键本地全流程”执行快照检查、逐币种精确金额、资金/IP模式、产业订单与来源、窗口规划、适配模型、完整报告，导出后再次核对快照。

没有适配模型或任务定义时，统计、图谱、IP/产业关联及人工核验仍可运行，模型显示未评分原因。“全流程完成”表示编排结束，不等于全部模型可评分或业务验收通过。

大图按原始事件分窗，保持同一时间参照、来源和每条记录的全部关系，默认每窗至多 256 节点/128 事件、重叠 24 事件、最多 64 窗。明确覆盖率和截断。完整金额按原图计算，不能相加重叠窗口金额，不能把窗口分数合成整案概率。模式列表或回流搜索截断也提示缩小时间范围复查。

资金路径是时序关联，不证明同一笔钱；共享 IP 不自动认定同一人。角色层级与控制方向分开监督。交易总额不等于涉案本金，覆盖率情景需要人工假设和依据。

## 真实模型与独立实证

1. 由提供方在 `case_labels.csv`、`person_labels.csv`、高级 `control_labels.csv` 提供有来源、经核实的标签。未知关系不填负类；标签表、姓名/来源角色不进入特征。
2. “任务与分组配置”在新副本填写资金正负含义、角色/层级及允许组合、控制任务。配置不创建监督标签。高级任务和原始媒体对应按数据字典填写。
3. 核实 `evaluation_groups.csv`：每个真实案件至少一条 `case_group`；同团伙关联案件共享组号，可另加人员、组织和来源批次组。同一团伙跨地区不能强行视为独立。分组须经提供方核实并引用当前来源。
4. 按完整案件时间切分训练/验证/内部测试。声明组、账户/钱包、同域IP、相同原始媒体跨集合时阻止训练。应重整数据批次，不能改组号绕过；程序无法发现未知的全部关联。
5. 资金训练至少 20 个满足类别及时间切分条件的有标签案件；人员/联合训练也需足够案件和完整类别支持。工程最低数量不等于统计充分样本量。
6. 原始媒体可选，只启用训练中实际存在的模态，未训练分支屏蔽。已训练但缺失的模态保留缺失标记。联合编码前需来源、指纹、人工对应、核验人和可用时间，不自动绑定主体。
7. 冻结权重、温度及阈值后，在“外部实证评测”选择完全独立的数据和冻结模型，提前填写业务验收标准。预填数量/比例只是示例，**不是行业标准**；不能看过外部结果再调标准当作独立验收。
8. 同来源/同任务、关联组及已知资产/媒体隔离通过后，输出案件、人员、控制对、地区/案型分组、错例、拒判、覆盖率和区间。未预测的已标注控制正例仍计漏判；不能只报可用样本准确率。人员验收不与资金二分类混用，联合验收同时检查资金、人员及控制指标。
9. 分组 bootstrap 整组采样；Wilson 按案件区间在组内相关时只作参考。小样本/零错误会产生不稳定或退化区间，不证明100%泛化。
10. 人工核对标签、范围和限制后登记复核。仅真实模型、真实外部数据达到预设规则，报告/数据/权重一致时允许登记通过。合成结果不能勾选成真实实证通过；本地记录不是数字签章或法律认证。

当前没有真实数据，真实训练与效果未实测。首次实证保留人工逐案复核和误报/漏报，确认适用范围后再决定使用方式。

## 备份与恢复

模型版本页可切换校验过的旧权重引用，不删除历史版本，来源/任务不匹配仍拒绝评分。

私有备份包含当前数据及原件、一致的核验数据库、源码/说明、当前三类模型、本地语音权重、工作区内实证报告及复核记录。全部历史模型、其他数据集、全部导出/缓存不在备份承诺内；外置报告需单独保管。备份未加密，是私有文件，不进入通用交付 ZIP。

恢复只写新的空目录，逐文件校验、核对数据指纹，模型使用相对引用。本机使用原项目解释器运行恢复目录 `app.py`；其他电脑需重建锁定依赖。本轮未实测全新机器安装。

审计链检查本地一致性，核验与审计写入同一事务。升级时封存旧日志，但不能证明升级前从未改动；持有本机文件者可能同时修改数据库与校验信息，不是可信外部时间戳或防篡改认证。
