# 第三方模型与依赖

项目的资金图模型和人员双头图模型是NumPy实现的可训练模型；OCR和语音基础能力使用现成公开模型，并未从零预训练。

- 本地OCR：rapidocr 3.10.0及其轮包附带的PP-OCRv6小型检测/识别和方向模型；ONNX Runtime在CPU推理。[RapidOCR官方项目及许可](https://github.com/RapidAI/RapidOCR)
- 本地语音：Systran转换的Whisper base/CTranslate2权重，[官方模型卡](https://huggingface.co/Systran/faster-whisper-base)标注MIT。Whisper原项目许可原文保存在licenses/Whisper_LICENSE.txt，版权归原作者。[Whisper许可](https://github.com/openai/whisper/blob/main/LICENSE)
- 音频推理：[faster-whisper](https://github.com/SYSTRAN/faster-whisper)；媒体解码PyAV、视频帧OpenCV；PDF使用pypdf及pypdfium2，DOCX使用python-docx，图像使用Pillow，投影使用scikit-learn。
- 主要版本在requirements.txt，当前完整环境在requirements-lock.txt。安装包保留各自许可证；交付包不复制本机Python环境。
- 公开权重文件来源和当前SHA256在runtime/models/public_models.json；这些哈希用于文件版本复核，不证明识别结果正确。模型准备脚本只下载公开权重；实际材料处理不自动联网。
