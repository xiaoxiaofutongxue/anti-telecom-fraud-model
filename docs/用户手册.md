# 用户手册（1.4.0）

## 双图与原始多模态联合研判

进入“人员·因果·材料”→“双图·多模态联合研判”，先点“载入双图样例”，再点“联合研判与解释”。核对候选人员、定向联系、四流模型解释、多目标核验问题和每份媒体的采样范围，使用“打开本次输出”查看独立报告。切换数据/案件/时间或模型后会清除旧结果，需要重新分析。

“地区/案型合成验证”使用冻结后另生成的三个24案集合；“选择外部数据评测”支持自己提供的独立标注数据。模型不在评测时更新。合成模型不得对真实案件评分，外部数据共享训练资产/IP/媒体时拒绝评测。真实世界团伙/人员独立性仍需业务检查。

“高级数据模板”导出data/advanced_templates_1_4格式。实际训练需至少12案，资金/角色/层级/控制任务和正负类别齐全，三类原始媒体都有训练样本；未知控制关系不填负类。媒体对应必须先由人工核对，辅助表改动后更新清单指纹。

原始模型是CPU轻量研究编码：图片32×32、音轨8000Hz前4096采样、视频全时段4帧，视频音轨另登记。它不承担完整视听语义、身份识别或违法认定；长材料使用独立OCR/ASR模块。HD-EIA/MOID-XAI为依据材料功能描述定义的自主工程实现，详细架构、损失与限制见《1.4联合模型与验收》。

## 1.3全流程自测

在“模型与迭代”点击“全流程模拟自测”，等待日志结束，再点“打开自测报告”。默认12个合成案件，包含7条问题记录及缺流、历史核验、材料导入、报告校验。所有模拟数据和核验库在runtime/simulations的独立目录，不更改当前案件或模型。通过、需关注和失败分别列出；模型有误报/错分时保留并标为需关注。

人员记录不足、缺少训练必备流、输入偏离或组合冲突时暂不分类，不产生相应层级连线；内部候选分布仅供复核。图谱较密时默认减少名称，可勾选“全部节点名称”；名称选择器不会合并同名对象。

## 启动与主流程

本机双击 D:\Projects\FourFlowAnalysis\启动系统.vbs；或在PyCharm中使用项目.venv解释器运行 app.py。停止旧版本再启动新版。默认增强合成样例用于熟悉系统；真实记录通过“导入数据目录”选择新的脱敏数据目录。

按案件和“截至时间”确定分析范围。空白使用全部导入记录，不带时区的时间按北京时间。四流显示复选框仅影响图像；完整分析、模型和报告仍使用当前案件快照。

“四流图谱”点击节点/边查看来源，选择起终点、币种和跳数查询逐笔路径。默认时间非递减；平行交易各保留编号，候选身份不进入推理。最多显示150节点，路径最多3条；若搜索提前到上限会提示未穷尽。

## 清洗、产业溯源和双图

“清洗与质量”将符合模板表头的原始数据清洗到互不包含的新空目录，原数据不修改。缺失、冲突、无效金额/IP等记录会隔离，查看 cleaning_report.json；不能把valid=true理解为被隔离记录无须再查。

“IP与产业溯源”调整网络分钟窗和产业小时窗，查看同订单四流来源、优先级和材料缺口。分数是核验优先级。共享公网IP、NAT、设备/账户对应仍需来源核实。

选择PCA、LDA、LLE或t-SNE后点击“查看节点投影”。LDA需要至少两类核实人员角色标签，只投影人员；它使用已知标签，因此画面分离不能用作预测成绩。

“四流图谱”中的“事件轨迹图”显示第二张事件DAG；点击事件可查看记录、时间和来源并打开材料。窗口显示前200事件、报告SVG前40事件，完整结构在behavior_graph.json；总事件超过10000条时明确停止构建，原始统计不截断。边仅表示同实体先后出现。

## 人员角色与层级

进入“人员·因果·材料”→“人员角色与层级”。

- 查看当前案件候选角色、层级、允许组合分数；点一行看两个输出头的分布和已有来源联系。分数经过允许组合归一化，不是成员真实身份或违法概率。
- 低分、两个输出头不兼容或允许组合质量低时提示优先复核。候选上下层按预测层级组织，不能认定指挥和控制。
- “合成角色训练验证”优先使用本轮96个合成案件的压力训练集，实际更新图卷积和两个分类头，输出模型卡、分组、训练曲线和留出测试指标。自带旧训练集保留为历史示例。
- “用当前标签训练”需 manifest.role_task 和 person_labels.csv；至少12个案件、30名经核实人员，训练/验证/测试中每种角色与层级均须出现。事件和标签可用时间不能跨越集合；共享资产/IP跨集合会停止。
- 合成权重无法对真实数据评分，任务定义不一致也会停止。真实训练需自行核实标签并进行外部验证。

## 因果分析与偏差

进入“因果分析与偏差”。

1. 首次点击“载入合成因果研究”，查看处理、结果、调整变量、800条观测和声明DAG；合成生成器的假设确认只适用于该测试机制。
2. 点击“执行调整与稳健性检查”，查看未调整差异、AIPW总体效应、近似95%区间、协变量平衡和压力检查。
3. “打开本次研究输出”进入版本目录，report.html可离线阅读；result.json、design.json、sources.csv、balance.csv、cross_fit.csv和checksums.json保留计算、设计、来源及复核信息。
4. 真实研究复制 data/causal_templates，先由业务人员定义队列、二元处理、后续结果和处理前变量，正确设置相关观测的group_id。至少50条、10个独立组，组大小不能高度集中，两组各至少10条；字段含义见数据字典。
5. 真实研究加载时不代填假设确认；逐项复核并填写确认人后才能估计。后门路径未阻断、处理后变量或来源/时间无效时会停止；重叠不足只输出诊断。
6. 默认不附到个案报告。勾选附件后仍作为独立队列研究，不能解释为当前个人的因果结论；与案件来源类型不匹配时拒绝导出。

DAG与无未测混杂、组间独立等假设不能由程序证明；稳健性检查、平衡改善和窄区间也不能保证无偏。

## 原始材料识别

进入“原始材料识别”。

1. “合成图片演示”可先验证。更多合成文件在 data/media_demo；真实材料选择本地文件并保持real来源。
2. 点击“本地识别”。图片/扫描PDF用本地OCR；DOCX提取段落、表格和内嵌图；音频使用本地Whisper；视频按时间均匀抽帧并尝试转写音轨。材料不上传。
3. 输出目录包含原机器文本、片段与定位、候选字段及来源SHA256。OCR置信度不是事实真实性；语音保留原始logprob等诊断，不捏造准确率。
4. 人工核对和修订文本，选择当前案件已有发送/接收主体，填写来源中的事件时间和核验人，勾选确认后点击“确认并生成/载入通信草稿”，选择D盘保存父目录。
5. 系统另建数据集、复制原材料及确认记录、保留原始记录行号/哈希；只增加通信摘要。不会把识别出的金额自动变为交易，或自动增加身份映射。真实材料不能导入合成数据集，反向也禁止。

默认限制：单文件500MB、图像4000万像素；PDF/多帧图像前100页、DOCX内嵌图前40张；音轨600秒；视频最多30帧，目标间隔10秒，长视频会拉开采样。截断、无音轨或失败会明确提示；不能把未提取内容当作不存在。程序接口可设置较高上限，长音轨建议先分段。

没有实现人脸识别、说话人身份确认、场景物体识别或完整视听语义融合。

## 核验、金额与报告

“模式核验”“主体与身份”保存核验人、依据及状态，保留来源原始标注和每次人工意见。确认/排除从实际核验时间生效；历史快照不显示未来意见。

金额统计按币种保留十进制精度。总交易额可能多次循环，不能当作本金。情景金额需要人工输入经核实去重本金、币种、覆盖率和来源，结果是条件情景区间。

“导出分析报告”生成带时间戳目录与ZIP。HTML、SVG、JSON、CSV包含四流、来源、核验、产业链、角色候选与层级图、行为图及可选独立队列研究。报告校验数据/图谱/核验/模型快照，出现不一致时重新分析后再导出。

## 本地文件和重建

源数据只读；核验库在runtime/analysis.sqlite3，模型在runtime/models，材料识别和研究分别在runtime/extractions、runtime/causal_runs，报告在exports。下载脚本显式联网准备公开模型，材料推理只读本地权重。

交付包不含个人核验库、设置或虚拟环境。其他电脑按README安装锁定依赖再启动；当前本机已配置。单用户本地应用尚未实现单位级多用户权限、加密存储、外部采集和自动调证。
