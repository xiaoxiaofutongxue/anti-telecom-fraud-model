# 1.4 双图、原始多模态与多目标联合模型

日期：2026-10-28。继续对照《模型大纲》及《第一章 执行摘要》1.2、1.3节。

## 本轮交付结论

已从原来的独立图谱/识别模块补成可训练的实体—事件双图联合网络，增加原始像素、波形、视频帧编码，有监督定向控制关系，MOID-XAI工程解释，以及冻结模型后的地区/案型留出评测。旧资金、角色、因果和材料识别功能继续保留，联合模型有单独的模型指针，不覆盖旧模型。

**原材料未给出HD-EIA、MOID-XAI的公式、论文或参考代码。** 本项目按其功能描述定义了工程实现，下面给出具体结构与验证。不能把此交付称为某个未提供规范的同名算法的完整复现。

真实材料、真实控制标签及独立地区数据目前仍未提供。因此实现和合成验证可以完成，真实团伙关系恢复与现实泛化成绩不能由程序生成出来。

## HD-EIA工程实现

1. 原严格清洗器负责格式标准化、去重、冲突隔离、引用完整性及逐行来源。高级清洗额外保留控制标签和媒体对应清单，并重新检查对齐。
2. 以唯一原始记录构建事件节点；实体和事件用发生矩阵C连接，不把一条原始记录展开的多条边当作多份证据。
3. 实体图使用29维输入、四流正反8个时间衰减通道；行为图使用10维事件输入和正反时序通道。每图两层可训练图卷积。
4. 两图通过归一化发生矩阵双向传递、门控融合，所有卷积和交互参数一起反向传播。事件先后与共享实体仍是观测关系，不是因果边。
5. 媒体必须登记具体事件、来源编号、文件相对路径/SHA256、核验人及可用时间。未经确认、越界、指纹不符、重复登记或事件不存在时拒绝接入；历史快照排除未来才可用的材料。

## 原始视听端到端编码

- 图像：RGB像素，经可训练二维卷积编码。
- 音频：本地解码单声道波形，经可训练一维卷积编码。
- 视频：全时段抽4帧，经图像卷积和可训练时间卷积编码；音轨需要单独登记音频对应。
- 通信文字：UTF-8字节嵌入，掩码池化；不把文件名、身份姓名、标签或控制表作为文字特征。
- 三原始模态与文字采用缺失掩码和注意力融合；训练中加入模态遮蔽，缺失模态不会伪装为黑图/静音证据。

这是**CPU轻量研究编码**：图片32×32；音轨8000Hz前4096个采样，即0.512秒；视频全时段4帧。原始网络没有预训练视觉/语言知识，合成媒体是观测时间绘图、调制音和平移视频；不是人脸、说话人、真实场景或视听语义识别。完整OCR/ASR仍由独立材料模块处理。每份原始媒体的采样限制保留在输出，不能把未采样内容解释成不存在。

## 监督任务、偏差处理与选择

联合优化四个监督头：图级目标资金模式、人员角色、人员层级、人员对的定向控制候选。控制标签由独立表给出，必须有明确来源、确认状态及标签时间；没有标注的人员对用-1掩码排除，不能当作负类。

复合目标：资金BCE + 角色CE + 0.6×层级CE + 0.7×控制BCE + 0.03×双图表示对齐。角色/层级训练用0.03标签平滑；控制正类权重3。隐藏维24，AdamW学习率0.006，梯度裁剪5。

本轮96案，按完整时间区间分57/19/20案，576名有标签人员及96名未标注背景人员；归一化只拟合训练集。事件、标签及媒体可用时间不能跨集合；共享资产/IP、相同媒体跨集合会停止。原始媒体不编码监督标签。

实际训练两候选，均60轮、固定种子414：

| 候选 | 最佳验证复合损失 | 选择 |
| --- | --- | --- |
| 等域权重ERM | 0.20588145 | 选中 |
| GroupDRO | 0.20589401 | 保留对比，未选中 |

GroupDRO对训练域损失做指数权重更新，是训练域稳健目标，不能证明消除选择偏差或未测混杂。本轮没有证据说明它优于普通联合训练，因此采用预定验证规则选ERM。原独立队列AIPW因果模块仍单独使用，不能将其效应强行解释为个人控制关系。

四个输出头的温度和控制阈值仅拟合验证标签；选中控制阈值0.95。模型与选择指纹先保存冻结，之后才生成外部评测集合；没有按外部成绩重新训练、校准或替换权重。

实体、事件、交互、图像、音频、视频和控制头的首轮梯度均非零，证明这些分支确实参加训练；非零梯度本身不证明其现实语义有效。

## 控制关系候选与MOID-XAI

控制头学习有方向的人员对，不以“预测上游→预测下游”替代监督。显示候选还需：两端人员可分类、至少两条已有共同事件依据、超过验证阈值，并保持候选DAG。抑制环只是展示约束，不证明真实控制关系无环；没有候选也不代表没有控制。

MOID-XAI工程版包含：

1. 精确计算四流16种输入子集的Shapley贡献，固定完整输入的参考时刻；贡献和与全量分数减空图先验相符。
2. 实体、事件、交互、全媒体、图像、音频、视频、文字八支路的遮蔽敏感性。
3. 节点梯度乘输入，以及对应原记录、来源编号、CSV行号和时间。
4. 资金、人员、IP和产业核验问题的覆盖、可追溯性、不确定性、影响四目标Pareto排序；权重逐项±20%后的名次范围。

这些是模型解释和核验资源排序。删除输入会改变分布，注意力、Shapley和梯度不是因果、违法或控制事实证明。

## 使用与自查

桌面进入“人员·因果·材料”→“双图·多模态联合研判”。先点“载入双图样例”，再点“联合研判与解释”；可做清洗对齐自查、外部域合成验证，或使用自己经核实的标签训练。输出在runtime/joint_runs、runtime/domain_runs。报告导出会校验数据、辅助文件、图谱快照，拒绝混入旧联合结果。

真实接入使用data/advanced_templates_1_4空模板及其中说明。真实模型与真实数据须任务一致，合成模型不得对真实案件评分。外部评测还需业务上按团伙/人员/来源独立分组，程序当前只能查已登记资产/IP/媒体重叠，不能发现未知同团伙关系。

源码入口：hd_eia.py、dual_model.py、moid_xai.py、domain_validation.py；批量入口见cli.py的joint-train、joint-predict、domain-evaluate、hd-eia-clean与hd-eia-audit。

参考：[PyTorch官方安装](https://docs.pytorch.org/get-started/locally/)、[DomainBed原论文](https://arxiv.org/abs/2007.01434)。采用CPU版torch2.14.1，材料不上传。升级前1.3包、核验库与设置备份位于D:\Projects\_archive。
