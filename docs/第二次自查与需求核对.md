## 已修复的实质性问题

| 检查项 | 原问题 | 修复后的行为 |
| --- | --- | --- |
| 历史核验 | 仅存最新状态，历史报告可能带入未来意见 | 每次核验保留版本；截止时间只取当时已生效意见。旧库从已有审计和最新状态恢复可得版本；不编造缺失历史 |
| 身份排除 | 来源已核实项不能方便复核，图谱和报告的有效状态逻辑不同 | 原始标注保留；人工可确认、排除或退回待核验。推理图谱、身份表、线索清单和报告使用同一状态；排除项不继续作为未知身份线索 |
| 事件时间与核验时间 | 容易将本次确认时间当成原始事件时间 | timestamp保留来源事件时间，effective_from单列核验生效时间；不把今天的意见放入过去快照 |
| 标识碰撞 | 冒号拼接的域与账户极端情况下同名 | 对复合标识分量进行无歧义编码；普通地址保持可读，不误并不同域账户 |
| 产业关联扩展 | 新加入主体可能继续扩展到无关身份，结果依赖遍历顺序 | 固定原始产业参与者和直接付款账户集合；增加回归检查确保边顺序不改变关联集合 |
| 长跨度订单 | 首尾运输记录相隔很久时，窗口可能覆盖中间整段时间 | 背景通信/IP须落在具体产业事件的回看窗口内，间隔期记录不自动拼入 |
| 来源多样性 | 一个文件换多个来源编号可能抬高排序 | 优先按材料内容哈希分组，无本地文件时按引用分组；材料组数量不声称来源独立性已验证 |
| IP账户记录 | 只有账户、尚未识别主体的网络日志可能漏掉共享IP提示 | 支持多个来源账户的共享IP观测；不从共享IP推断同一人 |
| 非公网网络域 | 特殊地址可能被当公网，内网可误用global域 | 组播地址不使用公网域；非公网禁止使用保留域global；按实际来源网络域隔离 |
| 清洗来源映射 | 再次清洗可能丢失最初行号；修改后仍沿用旧映射 | 输出CSV哈希、每次清洗阶段及最初输入映射均保留。文件变化后明确提示，失效的原始行号标为未知；声明但缺失的清洗报告拒绝导入 |
| 金额精度 | 默认28位十进制上下文可能使大金额与小额相加时舍入 | 汇总和净流入按输入尺度提高计算精度；情景区间向外取整。金额格式容量为1000位有效数字、指数绝对值不超过1000，超限明确拒绝 |
| 高密度重复交易 | 未达到不同对手方阈值时可能反复扫描整个窗口 | 拆分/归集使用滑动窗口统计不同对手方；1200笔同一对手方交易不会被误认作拆分或归集 |
| 训练时间切分 | 只按案件最早时间排序，训练案件后续事件仍可能越过验证区间 | 同时核对完整事件区间；跨集合时间交叠或共享地址/账户/同域IP均停止训练，避免虚假的时间留出评估 |
| 敏感性分析 | 删除某流后重算时钟，会让其他流突然变新 | 保持原图参考时刻；有截至时间时采用该时刻。删除关系及其特征贡献，保留节点基础类型，不称为因果干预 |
| 模型目标 | 0/1没有强制声明任务含义，存在混用风险 | manifest和模型卡须明确task_id、正负标签含义；不一致或未训练的权重不能评分。当前任务是合成资金组合模式，不是诈骗法律判定 |
| 重合样本提示 | 同一训练案件取历史子图后可能不再触发完整图重合提示 | 同时检查共享地址/同域IP，部分子图也会提示不能作为独立外部测试 |
| 图谱和报告快照 | 图生成后核验变化，可能混用旧图、新意见与旧分数 | 导出前校验数据版本、核验版本、模型图指纹和路径；不一致要求重新分析 |
| 界面数据范围 | 原始记录页与身份页可能显示截止时间之后的事件 | 有事件时间的记录按已应用截止时间显示；无时间元数据仍按当前导入版本展示，不伪造历史来源日期 |
| 后台任务 | 回调异常可能使后续导入和训练消息停止刷新 | 捕获结果应用错误并继续轮询，允许修正后重新操作 |
| 模型版本 | 批量训练可能覆盖current目录 | 默认使用独立版本目录；非空输出目录拒绝覆盖，旧模型保留 |

## 与两份要求材料的逐项核对

| 材料中的要求 | 当前状态 | 仍存在的差距 |
| --- | --- | --- |
| 资金、信息、IP、人员及产业记录统一 | 已实现结构化输入、图谱、时间分析和来源链 | 需要提供符合模板、已脱敏且有来源的数据；不是任意文档自动抽取 |
| 数据清洗与标准化 | 已实现规则清洗、错误隔离、重复处理、质量报告和可核对来源映射 | 不是已训练的HD-EIA神经清洗模型；不自动补造缺失事实，也未完成原始图片/音视频识别 |
| 动态异构图卷积与四流融合 | 已实现两层关系图卷积、时间衰减和图级二分类训练 | CPU本地小模型，每图最多256节点；没有实现大规模分布式训练或逐项论文复现 |
| 资金与信息、人员联合溯源产业流 | 已实现显式订单付款、产业参与者与窗口内背景记录关联 | 依赖输入中已有订单等明确关联；不会从三流自动发现未知产业订单或恢复未知供应商；目前产业记录仍复用运输数据结构 |
| 多目标侦查决策与MOID-XAI | 部分实现：透明权重、帕累托排序、图模型分数及敏感性提示 | 不是已训练的多目标决策神经模型；没有自动资源调度或执法行动决策 |
| 双轨知识图谱 | 部分实现：实体关联图、去重事件时间轴 | 时间轴不是第二个独立行为轨迹图神经模型 |
| PCA、LDA、LLE、t-SNE | 仅实现PCA探索并输出载荷与解释比例 | 其余未实现；PCA也未作为监督训练的降维步骤，不冒充完整降维算法组合 |
| 诈骗/违法认定 | 未实现自动认定 | 当前模型识别的是生成器资金模式标签；真实任务须重新定义标签、训练和外部评估，输出仍是辅助分数 |
| 团伙层级与核心人物 | 部分实现来源角色展示、结构社区与连接度 | 未训练真实成员角色/层级分类器，不能把中心节点认定为首要人员 |
| 涉案金额区间 | 已实现观测统计与人工覆盖率条件情景 | 不是已经学习的涉案本金预测或统计置信区间 |
| 因果证据链与偏差动态修正 | 未实现因果模型 | 时序关联、校准、特征偏离及敏感性分析都不是因果证明或因果偏差修正 |
| 实名化地址 | 已实现来源对应及人工核验 | 不自动反匿名化；未知身份保持未知 |
| 资金链图谱和调证清单 | 已实现图谱和建议核验清单导出 | 显示最多150节点；清单不是获批调证文书或完整司法证据交接系统 |
| 跨地区、跨案型普适性 | 保留区域和案型字段，案件可分别分析 | 没有真实跨地区外部验证，也没有跨案自动合并身份或联合查询引擎 |
| NeRF、NFC、APK、Agent调度 | 未实现 | 属于摘要更大平台中的方向，本次辅助模型不冒充这些系统 |
