# 反电诈辅助侦查模型优化与自查说明

> 历史记录：本文仅描述1.1；现有1.2功能与边界见《1.2升级与自查说明》和《需求覆盖说明》。

本次依据用户提供的项目执行摘要第1.2、1.3节及“资金、信息、IP、人员联合溯源产业流”的说明，升级为1.1版。目标是把多源记录转成可核验线索，支持人工判断。现阶段没有真实数据，附带数据、标签和训练结果均为合成验证。

本文记录1.1功能；1.1.1的修复与需求差距以《第二次自查与需求核对》为准。

## 输入与处理

1. 数据清洗：对模板CSV规范首尾空白、布尔、时间、币种和IP。规范千位分隔符可去除；完整相同的重复记录去重；同编号冲突整组隔离。缺失必要字段、金额错误、IP无效、主体或来源引用不完整的记录进入隔离清单。未知值不补猜，极端金额不自动当作噪声删除。
2. 结构化与溯源：保留原始文件，输出新目录及cleaning_report.json。保留每条变更、隔离原因、原始行号、输入文件SHA256；清洗内容和报告纳入数据指纹。表头须按模板对应，当前不直接解析任意银行账单、Excel、图片或聊天截图。
3. 实体关联图：资金地址和账户、主体、通信载体、IP、产业订单、运输地点和兑换事件按来源记录连接。主体ID、设备ID和订单ID在单案件内解释，跨案统一标识需要提供方先完成核实映射。账户按链或账户域区分；不靠字符串相似或共享IP自动合并身份。
4. 行为时间轴：每条原始事件只出现一次，按时间整理；付款、兑换等派生边不会重复增加原始事件数。导出behavior_timeline.csv。时间顺序表示记录次序，不等于同一笔资金或因果证明。

## 资金与网络分析

原有逐币种金额、短时拆分、归集、转入转出和回流结构分析保留。币种必须使用大写代码，避免usdt和USDT被误分成两类；交易额不直接当作涉案本金。

新增network_events.csv记录主体或账户在指定时间的网络观测，支持IPv4、IPv6、IPv4映射IPv6规范化。端口单独存放。非公网地址须填写network_scope，避免不同内网的同字符串IP误并；公网地址使用global域。

网络分析默认30分钟，可在界面调整到1至1440分钟，提供同窗共享IP、同一来源主体/账户短时多IP切换提示。事件按原始access_id去重，主体、账户和设备的派生边不重复计算访问次数。滑动窗口避免无匹配的大组记录逐次复制整个候选窗口。共享IP可能来自NAT或代理等情形，不用于自动实名绑定、物理定位或控制关系认定。

## 产业流联合溯源

旧货物流扩展为产业流。来源可指定通信设备、账户服务、软件服务、物流服务、其他或未分类。类别来自service_type，不由模型猜测合法或非法用途。

对每个产业订单，先查来源明确的同订单付款与产业记录，再加入付款前已生效的核实身份对应，以及相关主体/付款账户在时间窗内的通信、IP背景记录。默认窗口168小时，可调整为1至720小时。付款必须在首条发运记录之前且位于窗口内。没有明确订单关联的相近金额不会被拼入链条。

结果包含参与主体、账户、产业类别、地点路线、事件时间、来源编号、清洗前后行号及缺口。发现缺少付款、核实身份、背景记录、独立来源、物品标签冲突或运输地点不衔接时，会列出具体待补项。来源记录使用同一订单并不自动证明连续运输或同一批物品。

核验优先级由四流覆盖50%、来源多样性25%、付款与发运时间接近度25%组成，并标记帕累托前沿。此分数是透明规则排序，独立于神经网络，不是违法概率，也不是已经训练的犯罪决策器。界面、报告记录相同的时间窗参数。

## 模型变更

两层时序异构图卷积保留，增加IP节点和主体网络观测、账户网络观测、设备网络观测及反向通道，共29维输入、34种正反关系通道。加入同币种相对金额、不同IP数和网络事件数；原有图结构、四流计数、时间和通信摘要哈希特征保留。

金额先取自然对数，再减去当前案件图内同币种对数金额中位数，再汇总为节点入出特征；不把不同币种金额直接相加。极端相对差截到[-10,10]只用于模型特征，原始金额和统计不改写。主体名称、角色和标签文本不作为模型输入。

新增PCA使用NumPy SVD，对当前图的标准化节点特征提供二维探索、解释比例与载荷，保留原始特征。投影不用于身份合并、生成标签或监督训练；没有把PCA、LDA、LLE、t-SNE全部机械串联，也未声称实现所有摘要中的研究算法。

训练仍按案件时间60%/20%/20%分开；归一化仅在训练集拟合，验证集选择轮次和校准，测试集只作最终评估。共享账户或公网IP不能跨切分。缺标签不当作负类。新增特征与旧权重不兼容，已重新训练并保存模型版本；旧版本保留用于恢复。

## 自查修复

| 问题 | 修改与验证 |
| --- | --- |
| 缺少独立IP输入与网络观测 | 新表、图关系、时间窗、特征及报告；覆盖IPv4/IPv6、共享IP与非公网域隔离 |
| 清洗仅有格式拒绝 | 新目录清洗、冲突隔离、依赖过滤、质量报告与来源行映射 |
| 产业类别可能在图展开后丢失 | 所有运输派生边均保留类别和物品标签；核对溯源输出类别 |
| 多行CSV按记录序号显示行号 | 改用CSV解析器物理行号；同时保留清洗前后的行号 |
| 文本变更可能未影响训练集重合识别 | 图指纹纳入通信摘要、网络事件类型与网络域 |
| 历史截止到全部事件之前时模型尝试评分空图 | 空图不评分、不投影，保留可用的空分析结果 |
| 配置分析窗口后报告可能使用默认参数 | 参数传入报告，导出与界面保持一致，并写入analysis_options |
| 同记录可能同时触发不同模式 | 稳定编号及其验证按模式类型、节点和记录共同识别，避免把两类线索混为一条 |

## 尚未实现或证明

自动法律认定、无来源实名绑定、真实团伙角色/层级分类、可识别的因果推断与因果偏差动态修正，均没有实现或验证。原始图片/音视频识别、APK分析、NeRF、NFC硬件采集、自动外部情报采集和Agent自主调度，也不包含在本次模型实现中。当前两轨表示为实体图和事件时间轴，不冒充两个独立训练的图模型。

真实应用仍需经授权脱敏数据、明确任务标签、同主体关联分组、跨地区/跨案型外部测试和人工复核。当前合成模型不会为real来源数据输出研判分数。系统是本地单用户版本，未提供多用户权限控制或生产级案件管理。
