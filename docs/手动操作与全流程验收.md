## 5. 检索与筛选

进入“资料检索与原行”，输入 `58,379.20`，按回车或点击“检索本批资料”。当前三个原始文件应返回 **3 条完整数值匹配的原行**。选择其中“资产与坐标清单 / 38”，详情应显示付款人 FV-5、收款引用壳公司6、金额58,379.20美元及文书③段落47。

金额检索会归一化千位分隔符与末尾零；相同数值不证明同一笔支付。FV-1 等完整匿名编号使用边界匹配，不再误匹配 FV-10。一般文字问题仍使用相似度检索。

选择右上角流别并点“按流筛选”，会自动显示当前资料的相应原行列表。筛选只影响列表，摘要和报告仍覆盖整批资料。“恢复当前资料列表”退出检索，返回当前下拉所选资料与流别；如果要返回所有原行，先选“全部资料”。

## 6. 人工核验

点击一行，阅读详情和出处；“打开原件”打开项目保存的原件副本。按所示工作表和行号核对，不改写项目副本。若需要纠正输入，保存新的原始文件，再重新导入为新批次。

在页面下方选择状态、填写核验人和依据，再点击“保存本条核验”。核验人和依据不能为空。仅检查了程序操作、尚未核对原始文书时，可选“待补充材料”，如实备注“手动流程核验，尚未核对原始文书”；不要因此标记“已核实线索”。

“已排除”表示该原行不再参与当前分析，原件和原行仍留存。核验只作用于选中原行所属案件，即使检索结果来自其他案件。列表会直接显示核验状态。可再次保存其他状态，保留核验历史。

保存意见后，之前的报告仍是历史版本；点击“更新并导出报告”生成含新意见的结果。不要用旧报告判断刚刚修改的核验结果。

## 7. 打开和检查报告

点击“更新并导出报告”，等状态栏提示完成，再点击“打开研判报告”。也可点“打开报告目录”后双击 `index.html`。

报告首页点击案件名会进入本案目录，再选择“八项输出”“结构与核算”“资金与产业路径”“提及与时间”或“人工核验”。顶部“案件目录”和“导出文件”可在长报告中直接使用。点击“原行”应跳到相应记录；记录页可打开原件，也可“返回本案目录”。人工核验表应包含状态、核验人、依据和保存时间。

报告目录保存在项目的 `runtime\narrative_runs` 下，每次导出创建新的时间目录，同名 ZIP 在该目录旁边。重要文件：

| 文件 | 用途 |
| --- | --- |
| index.html | 离线阅读研判报告 |
| source_rows.html / sources | 原行定位 / 原件副本 |
| statement_payments.csv | 明示付款项目与日期对应 |
| hierarchy_candidates.csv | 明示关系方向候选及来源 |
| amount_reconstruction.csv | 名义合计、条件区间及假设 |
| reviews.csv | 当前核验意见 |
| result.json | 完整分析结构 |
| checksums.json | 文件一致性校验清单 |

## 8. 重启恢复

完成一次导出后正常关闭系统，再启动 `app.py`。应自动恢复上一批资料，并提示“已恢复匹配当前核验意见的报告，可直接打开”。无需重复导入，可以直接打开报告。

若数据、分析版本、核验意见或报告文件已变化，程序会要求重新导出，而不会把不匹配的旧报告当作当前结果。报告校验失败时，保留旧文件查明原因，再用当前资料重新导出。
