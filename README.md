## 案件文本直接导入

用户提供的三份四流分析工作簿现在可以整本直接导入：点击顶部“案件文本导入”，多选文件，等待自动研判。无需改表头或补逐笔流水。支持 XLSX、DOCX、TXT、MD 和粘贴文本。

输出原文事件、资金/产业回流路径陈述、主体/资产提及图、跨流会合提及、时间线、金额口径、资料检索和待核验清单，每条保留原文件及原表行定位。结果可导出HTML/CSV/JSON/ZIP；可保存人工核验并更新报告。

本入口使用本地文本解析、提及图和TF-IDF检索，不用三个样本训练分类器，不输出违法概率。余额、汇总、费用及行业数字不合计为交易总额，未知时间不补造。原有逐笔流水与监督模型在其他页面继续保留。

操作说明：[1.6案件文本研判使用说明](docs/1.6案件文本研判使用说明.md)。当前三个资料已作为本地私有批次接入，重启后可载入。通用源码ZIP不包含这三份原件和私人研判输出。

## 现在怎么启动

本机环境已配置好，项目在 D:\Projects\FourFlowAnalysis。

1. 双击“启动系统.vbs”，会直接打开桌面界面。
2. 也可用 PyCharm 打开本目录，解释器选择 D:\Projects\FourFlowAnalysis\.venv\Scripts\python.exe，然后右键 app.py → Run。
3. 运行旧版本时，先停止旧进程，再启动。不要运行 fourflow 内部模块文件。

进入“人员·因果·材料”，四个子页分别使用角色、因果、识别和联合模型。新版入口：“双图·多模态联合研判”→“载入双图样例”→“联合研判与解释”。默认工作台仍使用增强合成样例；数据、模型、识别输出和下载缓存都位于项目所在的D盘。

## 建议先走一遍

1. 在“人员角色与层级”查看六名合成人员的候选分类，点击一行查看双头分布和来源联系。合成训练按钮可重新完成训练、留出测试与保存。
2. 在“因果分析与偏差”点击“载入合成因果研究”→“查看声明因果图”→“执行调整与稳健性检查”。研究输出含可离线阅读的 report.html。真实研究需要分析人员重新确认假设。
3. 在“原始材料识别”点击“合成图片演示”。中文图片、扫描PDF、合成语音、视频等验证材料在 data/media_demo。文本可修订；填写并核对主体、时间和核验人后，才能另建通信导入草稿。
4. 在“IP与产业溯源”分析共享/多IP观测、同订单产业关联及材料缺口，可选择PCA/LDA/LLE/t-SNE探索特征。
5. 在“四流图谱”查询逐笔时序路径、查看“事件轨迹图”；最后导出含角色候选、层级SVG和行为图的报告。

所有模型候选和文本识别结果仍需核验。上下层箭头不是已核实控制关系；队列总体效应不是个人犯罪认定。

## 在另一台电脑重建

本机使用 Windows 64位、Python 3.13.5、CPU运行。本轮搬移与恢复使用既有虚拟环境，未实测全新机器依赖安装。交付ZIP是源码及模型包，不包含本机虚拟环境。将目录解压到D盘，在项目目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe app.py
```

安装依赖需要网络；材料识别阶段只读取本地模型，不上传材料。本GitHub源码版不包含 whisper_base 权重，显式执行下面的准备脚本下载公开权重：

```powershell
.\.venv\Scripts\python.exe tools/prepare_local_models.py
```

语音识别使用现成公开模型；四流资金和人员角色图模型为项目中的可训练实现。未声称从零预训练OCR或语音基础模型。
